# Reference analysis notes

## vishesh.dev — verified public implementation notes

- Public comment: React + p5.js + GSAP.
- Public comment: a small amount of Framer Motion was also used.
- Public comment: the home-screen paint interaction uses p5.js.
- Public comment: the creator later said that, if starting over, raw HTML/CSS/JS with Tailwind could be preferable for a site like this.

Secondary source: Vishesh Raheja's LinkedIn profile/post, which also states React, p5.js and GSAP.

## What we observed from the supplied videos

### Reference video: vishesh.dev
- Minimal editorial opening.
- Large type is the main visual anchor.
- Strong dark/neutral palette.
- Abstract interactive visual layer around the hero.
- Sections transition from large typography into editorial two-column layouts.
- Technology presentation is treated as visual content, not a plain skill list.
- Work is shown through large visual compositions.
- A numbered process section communicates the working method.
- Contact ends with a short, high-contrast CTA.

## What is intentionally improved in this starter

- The stack section includes an architecture visualization instead of only badges.
- Metrics have explicit labels.
- Experience bullets are compact and recruiter-readable.
- Projects explain the engineering problem, not only the technologies.
- Project visuals are original CSS compositions, so no external copyrighted assets are required to run the starter.
- The ambient canvas is implemented locally with p5.js and is pointer-aware.
- Reduced-motion support is included.
